# WorkBuddy 个人记忆系统 Skill

让任何 WorkBuddy 小白用户，通过自然对话，一键配好整套记忆系统，之后持续维护更新。全程不碰文件，全自动搞定。

## 做什么

| 阶段 | 触发 | 效果 |
|---|---|---|
| 首次初始化 | 说"配置记忆" | 6 问采集信息 → 自动生成 4 个文件 → 删除 BOOTSTRAP |
| 日常维护 | 说"记住 XX" | 定位目标文件 → 展示变更 → 确认后写入 |
| 记忆汇总 | 说"看看记住了什么" | 读取 4 个文件 → 表格展示 |

## 安装

将 `SKILL.md` 放到 `~/.workbuddy/skills/personal-memory-updater/` 目录下即可。

## 使用

1. 打开 WorkBuddy，说"配置记忆"或"让 WorkBuddy 了解我"
2. 回答几个问题（称呼、城市、身份、使用场景、偏好）
3. AI 自动配好所有记忆文件
4. 之后说"记住 XX"随时追加

## 文件结构

```
personal-memory-updater/
└── SKILL.md          # 完整 Skill 定义
```

## 隐私

所有文件存储在本地磁盘，不经过云端。写入前必有确认。
